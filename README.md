# Real Estate Market Intelligence & Property Price Analytics

An end-to-end data analytics project analyzing property prices, locations, property characteristics, and market segments using Excel, PostgreSQL, Python, and Power BI.

---

## 📌 Project Overview

This project analyzes a synthetic real estate dataset containing **25,000 property records** across **Mumbai, Thane, Navi Mumbai, and Pune**.

The objective is to clean and validate property data, perform SQL-based market analysis, conduct exploratory data analysis using Python, and develop interactive Power BI dashboards to identify pricing patterns, location-level differences, property trends, and market segments.

---

## 🎯 Business Problem

Real estate data contains multiple factors that can influence property pricing, including:

- Location
- Property type
- BHK configuration
- Property area
- Property age
- Furnishing status
- Parking availability
- Amenities
- Distance from metro stations
- Distance from city centers

The project uses these factors to answer business questions such as:

- Which cities and localities have higher property prices?
- How does property size relate to price?
- How does price vary across BHK configurations?
- Which property types dominate the market?
- How does property age relate to pricing?
- How are properties distributed across Budget, Mid-Range, and Premium segments?
- What property-level opportunities can be identified from the data?
